# Changelog

## v1.0.1 - 2026-07-19

- Aligned the MATLAB figure labels with the manuscript terminology and notation.
- Updated the manuscript title, release metadata, author affiliations, and persistent Zenodo concept DOI.
- Strengthened static checks against obsolete labels and unreplaced release placeholders.
- Preserved all equations, parameter values, tracked numerical records, and curated figure previews.

## v1.0.0 - 2026-07-10

- Replaced the four dark README previews with light-background exports generated by the release scripts.
- Expanded the figure captions so that the plotted quantities, parameter values, and thresholds can be read without opening the MATLAB files.
- Published the initial reproducibility package and archived it on Zenodo.

Initial reproducibility package for TFGBeta messenger KTAP simulations.

### Changed from working scripts

- Added `run_all_figures.m` release driver.
- Added MATLAB static/smoke checker `check_matlab_release.m`.
- Added Python repository checker `tools/static_check_repo.py`.
- Added `.mat` data export to S1-S4 scripts.
- Replaced fragile RGBA plotting properties in S4 with RGB-compatible properties.
- Changed S4 info box from `Stable focus` to `No Hopf detected` when no Hopf crossing is found.
- Aligned S4 gamma labels with the eight sampled gamma values.
- Removed Spanish editorial markers in S3 plotting comments.
- Added README, reproducibility documentation, GitHub/Zenodo release instructions, license, citation metadata, and release checklist.
